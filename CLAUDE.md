# Content Repo Instructions

## Published Folder Cleanup

Before every `git push`, clean the `published/` directory so it contains **only** files matching the pattern `YYYY-MM-DD <title>.md`. Remove everything else:

- `.html` files (generated by Quarto preview)
- `*_files/` directories (generated by Quarto preview)
- `.DS_Store` and other OS/editor artifacts

Run this before staging and pushing:

```bash
find published -type d -name "*_files" -exec rm -rf {} + 2>/dev/null
find published -type f -name "*.html" -delete
find published -type f -name ".DS_Store" -delete
```

## Workflow

- `draft/` — working drafts (not published)
- `published/<topic>/YYYY-MM-DD <title>.md` — finalized posts, one `.md` per piece
