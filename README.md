# Merrittocracy — Content

Drafts and published pieces for the [Merrittocracy](https://merrittocracy.substack.com) Substack and X account. Claude writes the initial drafts; I edit and publish.

## Structure

```
draft/        — works in progress
published/    — final, published versions
scripts/      — R scripts for tables and graphics used in posts
graphics/     — output from scripts (images embedded in posts)
```

## Scripts

| Script | Post | Output |
|---|---|---|
| `scripts/simpson_pickett_table.R` | Simpson/Pickett | `graphics/simpson_pickett_table.png` — four-way QB comparison table (Newton, Haskins, Pickett, Simpson) built with `gt` |
